# Contributing

Contributions should preserve the project’s evidence-first behavior and its separation from production systems.

## Before submitting a change

1. Keep edition and printing/cetakan as separate fields.
2. Do not infer missing bibliographic facts.
3. Preserve source identity, conflicts, and per-source errors.
4. Require server-side physical confirmation for ambiguous or review records.
5. Add deterministic regression tests in both runtimes when shared behavior changes.
6. Do not add production Site identifiers, private URLs, credentials, portraits, recovery archives, or compiled distributables.
7. Leave Indonesia OneSearch disabled unless permission or a supported access method is documented. Keep Google Books outside the combined view unless a compliant separate integration is designed.

Run the repository policy check and both test suites before proposing a change. Do not use a normal Zotero library for integration testing; use a disposable profile and obtain explicit user approval before any real write.
