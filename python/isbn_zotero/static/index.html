ISBN to Zotero

Built for Indonesian and older books. No metadata is invented. Conflicts remain visible.

Checking direct Zotero access…

A USB or Bluetooth barcode scanner normally types the ISBN here and sends Enter. One ISBN on Enter starts a search.

Catalogue service policy

Open Library is enabled and paced conservatively. Add OPEN_LIBRARY_CONTACT to identify regular requests.

Indonesia OneSearch is disabled by default until supported access is confirmed. It can be enabled for authorized private use with ISBN_ZOTERO_ENABLE_ONESEARCH=1.

Google Books is not queried in this combined catalogue view because its current branding rules prohibit intermixing its results with third-party results.
